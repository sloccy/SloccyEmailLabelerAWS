Classification model
Bedrock model used to label incoming emails. Sorted cheapest input cost first. Standard is normal-latency processing, limited to single-datacenter, US-, or Global-routed models; Flex is a discounted, lower-priority tier open to any flex-capable model regardless of routing region — higher latency, but still fast.
Prompt improver model
Bedrock model used for "Generate instruction" and "Improve rule". A smarter model here is fine since it runs infrequently. Same Standard/Flex tiers as classification — flex is discounted but lower-priority, which is fine for these occasional interactive calls.
Reasoning suppression override
Reasoning-capable classification models (Qwen3, Nemotron, etc.) are told to skip chain-of-thought automatically, based on the selected model's family — this costs nothing to leave blank. Only set this if your model isn't recognized yet: enter its "reasoning off" soft-switch text (e.g. /no_think) and it overrides the automatic choice. Check the logs after a classify run for a "reasoning: suppressed=true/false" line to confirm it's working.
Backup & Restore
Export all accounts, prompts, settings, and retention rules to a JSON file. Import adds data without overwriting existing configuration. OAuth credentials are not exported — you will need to re-authenticate accounts after import.
